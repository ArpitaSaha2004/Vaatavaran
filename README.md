# Vaatavaran

## Overview

Vaatavaran is a responsive weather dashboard web application developed using React to provide weather information, forecasts, air quality details, and other weather-related data for different locations.

The application includes dynamic weather-based visuals and animations for conditions such as clear weather, rain, snow, fog, clouds, and thunderstorms.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- React Router
- Lucide React
- Open-Meteo API

## Features

- Location Search
- Current Location Weather
- Current Weather Information
- Hourly Weather Forecast
- Daily Weather Forecast
- Temperature Unit Switching
- Air Quality Information
- Humidity Details
- Wind Information
- Sunrise and Sunset Details
- Weather-Based Themes
- Rain Animation
- Snow Animation
- Fog and Cloud Effects
- Thunderstorm Weather Effects
- Responsive Design
- Dynamic Weather Dashboard

## Project Structure

- `src/` - Main React source code
- `src/components/` - Reusable React components
- `src/context/` - React context for application state
- `src/pages/` - Application pages
- `src/services/` - Weather API services
- `src/utils/` - Utility functions
- `public/` - Public assets
- `index.html` - Main HTML file
- `package.json` - Project dependencies and scripts
- `vite.config.js` - Vite configuration

## Weather Data

**Weather API:** Open-Meteo

The application uses weather API data to display current weather conditions, forecasts, air quality, and other weather information.
